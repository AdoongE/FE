### 서비스 개요

Seedzip은 인사이트와 영감의 씨앗(seed)이 될 콘텐츠를 한 곳에 모아 관리하고, **필요할 때 활용**할 수 있는 서비스를 제공합니다.

- **AI 기반 추천 시스템**으로 제목과 태그를 자동 생성
- 웹과 앱을 모두 지원하여 기기 간 호환성 제공
- **링크, 이미지, PDF 저장** 지원
