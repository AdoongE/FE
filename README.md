## 개요 및 개발 필요성

안녕하세요. 유용한 디지털 정보를 한 곳에 모으고, 필요할 때 찾아볼 수 있는 서비스, **Seedzip**입니다.

### 리서치 배경

**디지털 저장 강박증**을 아시나요? 조금이라도 마음에 드는 정보를 무조건 저장하지만, 나중에 찾아보지도, 혹시 몰라 삭제하지도 못하는 것을 뜻합니다. 이러한 저장 습관은 많은 이들의 공감을 사고 있으며, 저희는 이를 해결하기 위해 3가지 초기 가설을 세웠습니다:

1. 사람들은 다양한 플랫폼에서 유용한 정보를 마주하고, **링크나 스크린샷** 형태로 저장합니다.
2. 저장한 정보들을 찾기 어렵고, 저장했는지조차 기억하지 못합니다.
3. 디지털 정보를 체계적으로 저장하고 쉽게 찾아볼 수 있는 솔루션이 필요합니다.

이를 검증하기 위해 설문조사와 인터뷰를 통해 사용자 리서치를 실시했습니다.

### 리서치 결과

- 사람들은 포털 외에도 다양한 플랫폼에서 링크와 이미지를 저장.
- 저장 목적 분석 결과, "**나중에**"라는 단어가 가장 많이 사용됨.
- 정보 저장 체계가 없어 저장된 정보를 찾기 어려움.
- 85.2%의 응답자가 체계적인 저장 솔루션 사용 의향 긍정.

### 기술적 필요성

- 저장 방식 간편성 및 **AI 추천** 시스템 필요.
- 분류 체계 및 검색/필터링 기능의 요구.
- **리마인더 기능**으로 저장 정보를 다시 활용 가능.

## Seedzip 솔루션

### 서비스 개요

Seedzip은 인사이트와 영감의 **씨앗(seed)**이 될 콘텐츠를 한 곳에 모아 관리하고, **필요할 때 활용**할 수 있는 서비스를 제공합니다.

- **AI 기반 추천 시스템**으로 제목과 태그를 자동 생성.
- 웹과 앱을 모두 지원하여 기기 간 호환성 제공.
- **링크, 이미지, PDF 저장** 지원.

### 주요 기능

1. **카테고리 및 북마크**
    - 카테고리 추가/수정/삭제 가능.
    - 특정 카테고리 북마크로 상단 고정.

2. **메인화면**
    - 반응형 디자인 적용.
    - 썸네일, 제목, 태그로 저장된 정보 확인 가능.

3. **링크 및 이미지 저장**
    - 클릭 시 해당 링크로 연결.
    - 이미지 및 PDF는 썸네일 확대로 상세 조회 및 다운로드 가능.

4. **AI 추천 시스템**
    - 링크 저장 시 제목, 태그, 요약 자동 제공.
    - 유튜브와 네이버 기사 링크는 AI 추천 태그 정확도 향상.

5. **검색 및 필터링**
    - 검색어 입력으로 저장된 정보 검색.
    - 태그 선택을 통한 필터링 가능.

6. **맞춤 필터 저장**
    - 세부 조건 설정으로 필터링 저장 및 재사용.

## 시스템 아키텍처

Seedzip은 **AI 추천 시스템**과 **검색/필터링 엔진**을 기반으로 동작하며, 웹 및 앱 사용자 경험을 최적화한 구조를 가집니다.

1. **프론트엔드**
    - React 기반 웹 UI 및 모바일 앱 UI 개발.
    - 사용자의 직관적인 정보 접근 및 저장 제공.

2. **백엔드**
    - Python 기반의 AI 추천 시스템 및 API 서버.
    - Django REST Framework를 통해 데이터 전달.

3. **데이터 저장**
    - MariaDB를 활용한 저장 데이터 관리.
    - AWS S3에 이미지 및 PDF 파일 저장.

## 실행 방법

### 웹 서비스 실행

1. **프로젝트 클론**
    ```bash
    git clone https://github.com/dudwntjs/seedzip.git
    cd seedzip
    ```

2. **필수 패키지 설치**
    ```bash
    yarn install
    ```

3. **개발 서버 실행**
    ```bash
    yarn start
    ```

### 앱 서비스 실행

1. React Native 프로젝트 구성.
2. Expo를 통해 모바일 환경에서 실행.
